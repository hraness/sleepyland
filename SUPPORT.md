# Support

- Use a [bug report](https://github.com/hraness/sleepyland/issues/new?template=bug_report.yml) for a reproducible product problem.
- Use a [research correction](https://github.com/hraness/sleepyland/issues/new?template=research_correction.yml) for an unsupported, outdated, or mischaracterized claim.
- Read [SECURITY.md](SECURITY.md) before reporting a vulnerability.
- Use the live [support page](https://sleepy.land/support) for browser-audio, privacy, or accessibility questions that do not belong in a public issue.

Sleepyland support does not provide diagnosis, treatment, medication guidance, hearing-safety certification, or crisis services. Do not post sensitive health or identifying information in GitHub issues.
